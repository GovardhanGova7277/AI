# Enterprise Sustainability RAG System & Audit Engine

An end-to-end, enterprise-grade **Retrieval-Augmented Generation (RAG)** pipeline built for parsing complex corporate disclosures, sustainability reports, and governance documents (Apple, Unilever, Coca-Cola). It features layout-aware document conversion, persistent vector storage, neural cross-encoder reranking, and automated Groq LLM quality evaluations.

---

## 🚀 Key Features & Tech Stack

* **Document Conversion (`Docling`):** Uses layout-aware PDF parsing (`PyPdfiumDocumentBackend`) to accurately retain markdown tables, headers, and hierarchical information that standard text-stripping parsers miss.
* **Persistent Vector Indexing (`LlamaIndex`):** Caches and serializes vector stores and document stores to disk (`./storage_index`), allowing instant restoration in <1s across sessions.
* **Precision Retrieval & Reranking:** Employs a two-stage retrieval pipeline—a broad coarse vector search (`similarity_top_k=15`) followed by a neural cross-encoder (`BAAI/bge-reranker-base`) to filter high-noise chunks.
* **Groq LLM Generation:** Powered by high-speed production models (`openai/gpt-oss-120b`) with strict anti-hallucination prompt templates enforcing inline source citations.
* **Automated Triple Evaluation:** Evaluates responses across three core metrics (Faithfulness, Relevance, and Conciseness) using native LlamaIndex evaluators and custom JSON LLM judges.
* **Production Serving:** Decoupled via a FastAPI backend bridge and an interactive Streamlit UI.

## ⚙️ Installation & Setup

1. **Clone the repository and install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Set up your Groq API Key:**
   Make sure you have your Groq API key handy when running the pipeline or starting your application server.

3. **Run the Ingestion & RAG Pipeline:**
   Execute your Jupyter notebook or python script cells sequentially to convert PDFs, build/load the persistent index, and execute grounded audit queries.

4. **Launch the Streamlit UI:**
   ```bash
   streamlit run app.py
   ```

## 📊 Evaluation Scorecard Framework

Every query processed through the engine is automatically audited against three rigorous metrics:
1. **Faithfulness (Anti-Hallucination):** Verifies that all generated claims are strictly supported by the retrieved source chunks.
2. **Relevance (Contextual Accuracy):** Confirms that the response directly addresses the user's prompt intent.
3. **Conciseness (Summary Efficiency):** Measures clarity and brevity, ensuring outputs are free of unnecessary filler text or repetition.
